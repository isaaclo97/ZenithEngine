# Soluciones de los ejercicios "Tu turno"

Una solución por lección (`00.yml` a `12.yml`). Cada una lleva al principio un comentario que explica qué se ha cambiado y por qué.

**Inténtalo antes de mirar.** Para comprobar tu propia solución, desde la carpeta de la lección:

```bash
cp ejercicio.yml mi_solucion.yml
python3 ../comprobar.py
```

Hay más de una forma correcta de resolver casi todos los ejercicios. Si `comprobar.py` dice "SUPERADO", tu solución es válida aunque no sea idéntica a la de aquí.
