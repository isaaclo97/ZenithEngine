# "Your turn" exercise solutions

One solution per lesson (`00.yml` to `12.yml`). Each starts with a comment explaining what was changed and why.

**Try it before looking.** To check your own solution, from the lesson folder:

```bash
cp exercise.yml my_solution.yml
python3 ../check.py
```

Almost every exercise has more than one correct answer. If `check.py` says "PASSED", your solution is valid even if it isn't identical to the one here.
