# Educational

Teaching material for **Zenith Engine**: hands-on lessons on the most common security flaws detected in real GitHub Actions workflows, each with a vulnerable example, a fixed example, a script that runs the engine's real detection rules and simulates the actual impact, a self-grading "Your turn" exercise and (where useful) an isolated Docker sandbox. It starts with a GitHub Actions fundamentals lesson (00) and ends with supply chain and typosquatting tips (12).

Available in two languages. Pick one; both cover the exact same 13 lessons (00 to 12):

- 🇬🇧 **[`en/`](en/)**: English
- 🇪🇸 **[`es/`](es/)**: Español
